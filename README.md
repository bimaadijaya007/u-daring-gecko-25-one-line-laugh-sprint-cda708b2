I asked my smart speaker to order toilet paper and it said, "You've ordered this three times this week — are you okay?"

A one-line joke about everyday life, written for the make.fun bounty "One-Line Laugh Sprint". The joke is about a smart speaker that orders toilet paper and answers with genuine concern — the device supposed to serve you ends up worrying about you.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly one line (119 characters) to `/output/entry.txt`. It is deterministic: running it twice produces byte-identical output. No network, no dependencies — Node.js standard library only.
